뽀모도로 타이머 웹의 메인 페이지를 만들어줘

- 일단 HTML, CSS만 사용해서 UI만 구현해
- HTML 배치
  - h1 태그로 "Pomodoro" 제목
  - 현재 남은 시간 표시
  - 시작, 정지, 초기화 버튼 배치
  - 설정 버튼 배치
- CSS 코드는 index.css 파일에 저장해줘
